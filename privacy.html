Privacy Policy — Tactical Attack Clips

Last updated: October 26, 2026

Tactical Attack Clips is a private tool operated by the owners of the Tactical Attack Show YouTube channel. It is used solely to upload video clips to the channel's own YouTube account through the YouTube Data API v3.

Information the application accesses

The application requests a single Google API permission: youtube.upload. This allows the application to upload videos to the YouTube channel of the account that authorized it. The application does not read, collect, or store personal information about any other person.

How information is used

OAuth authorization tokens are stored only on the operator's own computer and are used only to authenticate uploads to the operator's own channel. Tokens are never sold, shared, or transmitted to any third party other than Google's own API endpoints, which are required for the upload to work.

Data retention

The operator may revoke the application's access at any time from the Google account's security settings ("Third-party access"), which immediately invalidates the stored tokens. Stored tokens are deleted on request.
